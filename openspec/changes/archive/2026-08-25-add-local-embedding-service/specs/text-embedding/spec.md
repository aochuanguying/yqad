## Purpose

定义系统如何将文本转换为语义向量，作为内容去重、素材检索、主题推荐、敏感词变体检测、评论情感分析等语义能力的统一底层。向量必须反映真实语义，而非退化的占位值。

## ADDED Requirements

### Requirement: 生成真实语义向量

系统 MUST 通过 embedding 服务将输入文本转换为反映其语义的向量，相同语义的文本 MUST 得到相近的向量，不同语义的文本 MUST 得到可区分的向量。系统 MUST NOT 对非空文本返回恒定或全零向量。

#### Scenario: 语义不同的文本得到可区分向量
- **WHEN** 对两段语义明显不同的文本分别生成向量
- **THEN** 两个向量的 cosine 相似度显著低于去重阈值（0.90）

#### Scenario: 语义相同的文本得到高相似度向量
- **WHEN** 对两段内容几乎一致的文本分别生成向量
- **THEN** 两个向量的 cosine 相似度接近 1.0

### Requirement: 向量维度契约

系统生成的向量维度 MUST 与所配置的 embedding 模型维度一致，并与 ChromaDB 各集合创建时声明的维度一致。写入向量库的向量维度不一致时 MUST 视为错误。

#### Scenario: 维度与集合声明一致
- **WHEN** 生成向量并写入 ChromaDB 集合
- **THEN** 向量维度等于集合创建时声明的维度，写入成功

### Requirement: embedding 服务不可用时降级

当 embedding 服务不可达、超时或返回错误时，系统 MUST 以可预期的方式降级，不得中断调用方主流程，并 MUST 记录错误。降级产生的向量 MUST NOT 被误判为与历史内容高度相似。

#### Scenario: 服务超时降级
- **WHEN** embedding 服务在超时时间内未返回
- **THEN** 系统记录错误并返回降级结果，调用方主流程继续执行

#### Scenario: 降级不触发误判重复
- **WHEN** 因 embedding 服务不可用而进入去重检测
- **THEN** 去重逻辑不因降级向量得出"完全重复(相似度 1.000)"的错误结论

### Requirement: 空文本处理

当输入文本为空或仅含空白时，系统 MUST 以确定性方式处理，不得抛出未捕获异常。

#### Scenario: 空文本输入
- **WHEN** 输入文本为空字符串或纯空白
- **THEN** 系统返回确定性结果且不抛出异常
