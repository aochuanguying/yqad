# CarPlay 断开告警 - 极简配置

## 功能说明
当 iPhone 断开 CarPlay 时，自动调用告警接口，触发电话 + Bark 推送。

**不包含**：位置信息、延迟、条件判断等高级功能。

## 3 分钟快速配置

### 第 1 步：创建快捷指令（1 分钟）

1. 打开 **快捷指令** App
2. 点击右上角 **+**
3. 添加以下操作：

#### 操作 1: URL
搜索"URL"，添加：
```
URL: https://yqad.hxfssc.com:8088/api/vehicle-monitor/manual-alert
```

#### 操作 2: 字典
搜索"字典"，添加（**留空，不传任何内容**）：
```
什么都不用填！
```

**或者删除字典操作，直接传空对象**

#### 操作 3: 请求
搜索"请求"，配置：
- **URL**: 从"URL"操作获取
- **方法**: POST
- **请求体**: 从"字典"操作获取

展开请求（点击">"），添加请求头：
```
Authorization → Bearer api_token_1640a8b188784e52e08e11eb8dcab3a9fcea5a8d6b03e1235d6705938eed853a
Content-Type → application/json
```

#### 操作 4: 名称
给快捷指令命名：`🚗 CarPlay 断开告警`

### 第 2 步：创建自动化（1 分钟）

1. 切换到 **自动化** 标签
2. 点击 **创建个人自动化**
3. 选择 **CarPlay 连接**
4. 选择 **断开连接时**
5. 添加操作 → 搜索"运行快捷指令"
6. 选择 `🚗 CarPlay 断开告警`
7. 点击 **下一步**
8. ✅ **关闭"运行前询问"**（重要！）
9. 点击 **完成**

### 第 3 步：测试（1 分钟）

1. 手动运行快捷指令 `🚗 CarPlay 断开告警`
2. 等待电话和 Bark 推送
3. 确认都收到

## 常见问题

### Q: 自动化不触发？
A: 确保关闭了"运行前询问"

### Q: 网络不可达？
A: 确保 iPhone 能访问公网，或服务器已开放 8088 端口

### Q: 不想每次都告警？
A: 当前是极简版本，每次都会告警。如需更复杂逻辑，请查看高级版本文档。
