# iOS 快捷指令自动化配置指南

## 功能说明
当 iPhone 断开 CarPlay 连接时，自动调用车辆告警接口，模拟一次车辆异常检测。

## 前置准备

### 1. 获取 API Token
确保你已经有 API Token，用于调用告警接口：
```
api_token_1640a8b188784e52e08e11eb8dcab3a9fcea5a8d6b03e1235d6705938eed853a
```

### 2. 确认服务器地址
- **本地开发**: http://192.168.50.10:3000
- **生产环境（公网）**: https://yqad.hxfssc.com:8080

## 快捷指令创建

### 方案一：基础版（仅调用接口）

#### 步骤 1: 创建快捷指令
1. 打开 **快捷指令** App
2. 点击右上角 **+** 创建新快捷指令
3. 命名为：`车辆告警触发`

#### 步骤 2: 添加操作
搜索并添加以下操作：

**1. 添加"URL"操作**
```
URL: https://yqad.hxfssc.com:8088/api/vehicle-monitor/test-alert
```

**2. 添加"请求"操作**
- 点击"请求"
- 配置如下：
  - **方法**: POST
  - **请求体**: JSON
  - **URL**: 从"快捷指令输入"获取（上一步的 URL）

**3. 添加"字典"操作**（作为请求体）
点击"请求体"，选择"字典"，添加以下键值对：
```
键：anomalies
  值：["CarPlay 已断开"]
  
键：lat
  值：36.10772373923576
  
键：lng
  值：120.41258170164984
  
键：address
  值："CarPlay 断开位置"
```

**4. 添加"请求头"到请求**
点击请求的">"展开，添加请求头：
```
键：Authorization
  值：Bearer api_token_1640a8b188784e52e08e11eb8dcab3a9fcea5a8d6b03e1235d6705938eed853a

键：Content-Type
  值：application/json
```

#### 步骤 3: 测试
1. 点击 ▶️ 运行
2. 查看是否收到告警通知（电话+Bark）

### 方案二：增强版（带位置信息）

这个版本会获取当前真实位置，并发送到告警接口。

#### 完整快捷指令代码

```shortcut
// 快捷指令名称：车辆告警触发（增强版）

// 1. 获取当前位置
获取当前位置
  精度：最好

// 2. 创建字典（请求体）
创建字典
  anomalies: ["CarPlay 已断开"]
  lat: [当前位置的纬度]
  lng: [当前位置的经度]
  address: "CarPlay 断开 - [当前位置]"

// 3. 创建 URL
URL: http://192.168.50.10:3080/api/vehicle-monitor/test-alert

// 4. 发送请求
请求
  方法：POST
  URL: [URL]
  请求体：[字典]
  请求头：
    Authorization: Bearer api_token_...
    Content-Type: application/json

// 5. 显示结果
如果 [请求的响应] 包含 "success"
  显示通知 "✅ 告警已触发"
否则
  显示通知 "❌ 告警失败：[响应内容]"
```

## 自动化配置

### 创建 CarPlay 断开自动化

#### 步骤 1: 打开自动化
1. 打开 **快捷指令** App
2. 切换到 **自动化** 标签
3. 点击 **创建个人自动化**

#### 步骤 2: 选择触发器
1. 向下滑动，找到 **CarPlay 连接**
2. 选择 **断开连接时**
3. 点击 **下一步**

#### 步骤 3: 添加操作
1. 搜索 **运行快捷指令**
2. 选择刚才创建的 `车辆告警触发`
3. 点击 **下一步**

#### 步骤 4: 配置运行选项
- ✅ **立即运行**（重要！）
- ❌ 关闭 **运行时通知**（可选）

#### 步骤 5: 完成
点击 **完成**

## 测试验证

### 测试流程

1. **连接 CarPlay**
   - 将 iPhone 连接到车辆 CarPlay

2. **断开 CarPlay**

4. 查看 **运行记录**

## 高级配置

### 1. 添加延迟（避免误触发）

在触发告警前添加延迟：
```
添加操作：等待
  时间：30 秒
  
然后：运行快捷指令 `车辆告警触发`
```

### 2. 条件判断（仅在特定时间段告警）

添加条件：
```
如果 [当前时间] 在 [08:00] 和 [22:00] 之间
  运行快捷指令 `车辆告警触发`
否则
  显示通知 "⏰ 非告警时段，跳过"
```

### 3. 记录告警历史

添加操作：
```
追加到备忘录
  内容：CarPlay 断开 - [当前日期时间]
  备忘录：车辆告警记录
```

## 故障排查

### 问题 1: 自动化未触发
**原因**: 未设置"立即运行"
**解决**: 
- 编辑自动化
- 确保勾选 **立即运行**

### 问题 2: 接口调用失败
**原因**: 网络不可达
**解决**:
- 确认服务器地址正确
- 确认 iPhone 和服务器在同一网络
- 或使用公网地址

### 问题 3: 收到告警但无通知
**原因**: Bark 或电话配置问题
**解决**:
- 检查生产环境配置
- 查看服务器日志

## 安全建议

### 1. Token 保护
- 不要在快捷指令中明文显示完整 Token
- 定期更换 API Token

### 2. 访问限制
- 配置防火墙规则
- 限制来源 IP

### 3. 频率限制
- 在服务器端配置速率限制
- 避免频繁触发

## 扩展功能

### 1. 区分驾驶员

可以结合"快捷指令"的"如果"条件，根据不同 CarPlay 名称触发不同告警：

```
如果 [CarPlay 名称] 包含 "张三"
  anomalies: ["张三用车结束"]
否则如果 [CarPlay 名称] 包含 "李四"
  anomalies: ["李四用车结束"]
```

### 2. 发送详细位置

获取详细位置信息：
```
获取当前位置
  纬度
  经度
  海拔
  速度
  航向

创建地址簿
  输入：[纬度]，[经度]
  
获取地址
  街道
  城市
  省份
  
发送到告警接口
```

### 3. 多通知渠道

同时发送到多个渠道：
```
并行执行：
  ├─ 调用告警接口（电话+Bark）
  ├─ 发送微信通知
  └─ 发送邮件通知
```
