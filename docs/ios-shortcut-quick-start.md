# CarPlay 断开告警 - 快速配置指南

## 5 分钟快速配置

### 第 1 步：创建快捷指令（2 分钟）

1. 打开 **快捷指令** App
2. 点击右上角 **+**
3. 添加以下操作：

#### 操作 1: URL
```
URL: http://192.168.50.10:3080/api/vehicle-monitor/test-alert
```

#### 操作 2: 字典
搜索"字典"，添加：
```
anomalies → ["CarPlay 已断开"]
lat → 36.1077
lng → 120.4126
address → "CarPlay 断开位置"
```

#### 操作 3: 请求
搜索"请求"，配置：
- **URL**: 从"URL"操作获取
- **方法**: POST
- **请求体**: 从"字典"操作获取

展开请求（点击">"），添加请求头：
```
Authorization → Bearer api_token_1640a8b188784e52e08e11eb8dcab3a9fcea5a8d6b03e1235d6705938eed853a
Content-Type → application/json
```

#### 操作 4: 名称
给快捷指令命名：`🚗 车辆告警`

### 第 2 步：创建自动化（2 分钟）

1. 切换到 **自动化** 标签
2. 点击 **创建个人自动化**
3. 选择 **CarPlay 连接**
4. 选择 **断开连接时**
5. 添加操作 → 搜索"运行快捷指令"
6. 选择 `🚗 车辆告警`
7. 点击 **下一步**
8. ✅ **关闭"运行前询问"**（重要！）
9. 点击 **完成**

### 第 3 步：测试（1 分钟）

1. 手动运行快捷指令 `🚗 车辆告警`
2. 等待电话和 Bark 推送
3. 确认都收到

## 常见问题

### Q: 自动化不触发？
A: 确保关闭了"运行前询问"

### Q: 网络不可达？
A: 确保 iPhone 和服务器在同一网络，或使用公网 IP

### Q: 不想每次都告警？
A: 可以在快捷指令中添加条件判断，比如：
   - 仅在特定时间段
   - 仅在特定地点
   - 添加 30 秒延迟
